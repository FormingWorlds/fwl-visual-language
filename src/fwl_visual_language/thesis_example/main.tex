\guidesection{Using this template}
\guide{Grey text like this says what goes where. Write your own text below it. The class option \guidecmd{final} hides all grey text at once, so you can keep it while you write. Compile with LuaLaTeX; in Overleaf, set the compiler to LuaLaTeX in the project settings. Replace the example sentences, the equation, Figure 1 with its data, script and link, and the example reference with your own, and delete what you do not use.}
\guide{\textbf{Citations.} \guidecmd{\textbackslash citet\{key\}} cites in the sentence: \citet{Lichtenberg2021} show that \ldots; \guidecmd{\textbackslash citep\{key\}} cites in parentheses: \ldots{} \citep{Lichtenberg2021}. Take the BibTeX entry of each paper from NASA ADS (Export, BibTeX) and cite it with the key of its entry. Cite the journal version once a paper is published, not only the arXiv version. The common journal macros of ADS, such as \guidecmd{\textbackslash apj} and \guidecmd{\textbackslash mnras}, are defined; where LaTeX reports one as undefined, write the journal name in the entry.}
\guide{\textbf{Code and data.} All code and data of the thesis must be public. Put the code, the data, one plotting script per figure and a licence file in a GitHub repository. Make the repository public, connect GitHub to Zenodo and switch the repository on in the GitHub settings of Zenodo, then make a release: Zenodo archives it and gives each release its own DOI. Cite the DOI of the release you used. Every figure must be replottable from these files: name its data and script in the caption with \guidecmd{\textbackslash figuredata\{link\}}, as in Figure~\ref{fig:cooling}, which \guidecmd{scripts/plot\_cooling.py} plots from \guidecmd{data/cooling.csv}; replace the example link with the DOI of your release. A list of figures (\guidecmd{\textbackslash listoffigures}, after the contents) takes the short form of a caption, \guidecmd{\textbackslash caption[short]\{long\}}, so the link stays out of it. Cite the codes and data sets of others that you use, in the form their documentation asks for.}
\guide{\textbf{Figures and units.} Plot with the lab style fwl-mpl (install it with pip from \url{https://github.com/FormingWorlds/fwl-mpl}), save figures as vector PDF, label every axis with its quantity and unit, and use the colours of the style, which stay apart for readers with colour-vision deficiency. A caption starts with what the figure shows and says how to read it: what one line, dot or colour is, and where to look. Write numbers with units as \guidecmd{\textbackslash qty\{3000\}\{\textbackslash kelvin\}}.}
\guide{\textbf{Writing.} Give each paragraph one message, stated in its first sentence. Use the present tense for what the thesis shows and the past tense for what you did. Define every symbol where it first appears. Agree on the plan and the length of each section with your supervisor before you write.}

\begin{equation}
F = \varepsilon\,\sigma T_\mathrm{s}^4 ,
\label{eq:flux}
\end{equation}
